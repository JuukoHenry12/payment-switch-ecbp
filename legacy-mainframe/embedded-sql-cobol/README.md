# Embedded SQL COBOL Examples

Real DB2 embedded SQL COBOL programs, precompiled via DB2's actual
db2 prep precompiler running inside the db2-ecbp container.

## Files
- acctlook.sqb / .cbl - single-row SELECT INTO example (SYSIBM.SYSDUMMY1 timestamp query)
- extractacct.sqb / .cbl - cursor-based multi-row extract (DECLARE/OPEN/FETCH/CLOSE),
  writing results into an indexed COBOL file - demonstrates the pattern used to bridge
  modern batch-service extracts to the legacy-mainframe track.
- .bnd files - DB2 bind files generated by the precompiler

## How these were built

    docker exec -it db2-ecbp bash
    su - db2inst1
    . ~/sqllib/db2profile
    db2 connect to ECBPDB
    db2 prep FILENAME.sqb bindfile

## Notes
- Host variables must be declared inside EXEC SQL BEGIN/END DECLARE SECTION
- Numeric host variables matching a DECIMAL DB2 column need COMP-3 usage
- SQLCODE 0 = success, 100 = not found/end of cursor, negative = error
